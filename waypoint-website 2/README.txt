WAYPOINT — Gratitude journal website

HOW TO OPEN
1. Download and unzip the waypoint-website folder.
2. Open index.html in Chrome, Safari or another modern browser.
3. Internet is only needed to load the optional Google Fonts; the website itself works locally.

FEATURES
- Six connected pages: Home, New entry, Explore, Your progress, Reflection and Settings.
- Journal entries saved in browser localStorage.
- Gratitude prompts in five categories and prompt search.
- Entry tags and mood selection.
- Streak, weekly activity, mood summary and monthly calendar.
- Profile name and accessibility text-size / contrast settings.
- Optional 4–8 digit PIN screen.
- Export entries as JSON and delete local journal data.

PRIVACY NOTE
This is a front-end school project prototype. Entries and the optional PIN are stored in this browser on this device, not encrypted or synced to an account. Do not use it for highly sensitive information. Clearing browser data may remove entries. The PIN is a basic access screen, not strong security.
